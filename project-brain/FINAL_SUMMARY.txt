**Result:** All services running in 5 minutes + demo data loaded

### Method 2: Manual Docker Compose

```bash
cd project-brain
docker-compose up -d
sleep 15
```

**Backend:**

## ??? ARCHITECTURE HIGHLIGHTS

### DB-First Design
```
Single Source of Truth: PostgreSQL
    ?
Specialized Stores:
  - Qdrant (embeddings)
  - MinIO (files)
  - Neo4j (graph, optional)
  - Redis (cache/queue)
```

### Async Processing
```
Long-running tasks ? Celery + Redis
  - parse_document_task
  - embed_chunks_task
  - correct_transcript_task
  - extract_meeting_task
```

### Search Pipeline
```
Query ? BGE-M3 Embed ? Qdrant Search ? BGE-Reranker ? Results
```

### Data Flow
```
Document Upload
  ?
Compute SHA256 (idempotency)
  ?
Store in MinIO + Create DB record
  ?
Trigger async parse
  ?
Extract chunks ? Create DB records
  ?
Trigger async embed
  ?
Generate embeddings ? Upsert to Qdrant
  ?
? Document fully indexed
```

## ?? TROUBLESHOOTING

### Services Won't Start
```bash
docker-compose logs postgres  # Check error
docker system prune -a         # Clean Docker
./quick-start.sh              # Retry
```

### Port Conflicts
- Edit docker-compose.yml
- Change port mappings (e.g., "8001:8000")

### API Not Responding
```bash
curl http://localhost:8000/health
docker-compose logs backend
```

### Search Not Working
```bash
curl http://localhost:6333/health  # Check Qdrant
docker-compose logs worker         # Check embeddings
```
